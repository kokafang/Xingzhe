# 醒着 · Awake for macOS
仅顶栏的 macOS 工具，一个「保持清醒」开关，没有普通窗口或 Dock 图标。

## 使用
首次运行自动申请登录启动。第一次开启时，macOS 可能打开「系统设置 → 通用 → 登录项与扩展」，请批准「醒着」后台服务，然后再次打开开关。管理员身份不会跳过系统批准。

开启通过系统电源设置禁止睡眠，并用临时 IOKit 用户活跃/显示断言抑制空闲锁屏；关闭恢复开启前的 SleepDisabled 值，不改其他电源或密码设置。手动锁屏不会被解锁。

程序启动默认关闭。退出、连接断开、心跳超时（20 秒）会恢复。后台崩溃由系统重启，读取磁盘恢复记录；恢复失败保留记录并每 2 秒重试。系统强制停止/删除后台服务期间无法运行恢复，请先关闭开关再卸载。

## 构建
需要 Xcode / Swift，Apple Silicon macOS 13+。执行 `bash scripts/build.sh`，产物 `build/醒着.app`。构建包含恢复逻辑测试、代码签名及 plist 校验。本地 ad-hoc 签名，无需开发者账号，不是用于公开分发的公证版本。

构建后，将 `build/醒着.app` 复制到 `/Applications` 并打开。程序只显示顶栏图标。后台服务需要 macOS 批准，首次批准后再打开开关。

启动路径回归测试：`python3 scripts/test-launch-path.py`（先完成构建）。

## 项目结构
- `Sources/App`：顶栏界面、后台连接、临时防空闲断言。
- `Sources/Helper`：系统后台服务和电源配置。
- `Sources/Shared`：连接协议、签名验证和恢复逻辑。
- `Tests`：恢复机制测试。
- `Resources`：应用及后台服务配置。
- `scripts`：构建及启动路径回归测试。

## 验收
- 开启后确认顶栏太阳图标，SleepDisabled=1；关闭读回开启前值。
- 在目标 MacBook 上分别测试电池和接电：打开开关，合盖等待 1 分钟，确认任务不中断，开盖无自动锁屏。
- 关闭后合盖：应回到该电脑原有睡眠/锁屏行为（外接显示器等系统条件仍适用）。
- 开启后强制退出顶栏进程，确认后台恢复。
- 手动锁屏仍有效；企业强制安全策略不保证可抑制。

真实合盖和锁屏效果需要人工实测；读回电源设置不能替代此项验收。
